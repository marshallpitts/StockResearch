# Risk Allocator Research App
This is a small terminal based sample project for the Research Milestone

## Technologies
- Python
- Rich
- pip
- venv

## Features
- Enter an investment amount
- Choose a risk level
- Generate a sample allocation based on the selected risk level
- View the percentage and dollar amount for each investment
- View mock stock prices, whole shares, and leftover cash

## Run the project
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install rich
python main.py
